# BusyBox on Windows

An independently authored Claude skill for plan, install, configure, and troubleshoot busybox on windows environments.

## Contents
- `SKILL.md`: operating instructions, workflow, safeguards, and review checklist.
- `LICENSE`: MIT License.

## Use
Add this repository's `SKILL.md` to your supported skills directory or paste its instructions into your agent configuration. Follow the frontmatter name and description when registering the skill.

## Scope
This repository focuses on the workflow described above. It does not bundle third-party binaries, dependencies, or generated artifacts.
